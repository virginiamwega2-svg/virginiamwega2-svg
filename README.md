### 🌿 What I'm building

**[FamNest](https://github.com/virginiamwega2-svg/Famnest)** — an AI wellness coach for overwhelmed parents.
A 30-second daily check-in turns into a personalised plan, powered by a
**multi-agent pipeline** (a coach agent + a safety reviewer) with a
**deterministic crisis floor**, RAG grounding, and per-user memory.

> Built with Next.js 16, React 19, TypeScript, Supabase, and a swappable LLM layer.
